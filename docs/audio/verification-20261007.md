# CDN 配音与点词播放验收

## 已实施

- 客户端移除 TTS 生成请求、生成缓存与系统朗读回退。650 条配音统一读取项目内 CDN 映射，缺失音频显示“尚未配音”。个人练习录音仍保存在本地 IndexedDB，不上传。
- 内容制作阶段补配正文、口语示范和句型例句，共 61 段带字幕时间轴的 MP3。制作回执保存在本目录 `receipts/`，没有保存 MP3 文件。发现一条日语示范的字幕漏末句，单条重制后校验通过。
- 点词查看已收录释义、读这个词、从这里播放、播放到这里、加入复习。未收录释义的词可听上下文，不生成猜测释义。独立词条优先使用已有词条 CDN；其他词截取原文音频对应时间段。
- 正文、示范与句型例句共享播放器；支持暂停续播、进度拖动、0.8× / 1×、同步词高亮。切页或开始录音停止示范播放。
- 词汇与短语实线，句式虚线；标记有项目内说明与精确原文引用。日语保留振假名、词汇与常见礼貌形式边界。
- 移动端词语操作为底部浮层，点击外部关闭，切换段落的词不叠加面板；桌面使用段落内面板。

## 后续补充方式

新增内容后，在制作环境执行 `pnpm audio:generate --align`。只有缺音频或缺匹配时间轴的训练文本需要生成；匹配的资产会跳过。修改过的单条内容通过精确 `--key='语言:完整文本' --limit=1` 重制，避免整库重录。配音生成服务不属于浏览器运行流程。

时间定位使用服务提供的字幕，不按字数推算。即使所有词边界都有字幕，也不代表日语发音和时点已逐词人工审校，仍需要听感校对。CDN 未缓存时需要联网；本次没有新增离线缓存或 PWA。
