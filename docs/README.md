## 当前项目

- 产品：LinguaDesk，英日双语学习台。
- 技术栈：React 19、TypeScript、Vite 7、Less Modules。
- 运行形态：纯前端单页应用；学习材料内置，进度保存到当前浏览器。
- 主要功能：英日独立路线、完整训练单元、口语录音与回听、分级阅读与理解题、词汇/错题复习、假名、实际结果记录和含录音备份。
- 现有入口：[页面入口](../src/pages/Home/Workspace.tsx)、[学习状态](../src/study/TrainingProvider/index.tsx)、[项目脚本](../package.json)。
