## 当前项目

- 产品：LinguaDesk，英日双语学习台。
- 技术栈：React 19、TypeScript、Vite 7、Less Modules。
- 运行形态：纯前端单页应用；学习材料内置，进度保存到当前浏览器。
- 主要功能：今日任务、闪卡、口语、阅读资源、假名、30 天计划、词库。
- 现有入口：[页面入口](../src/pages/Home/index.tsx)、[学习状态](../src/study/StudyProvider/index.tsx)、[项目脚本](../package.json)。
