# 功能重构实施与验收

日期：2026-10-07。

## 已实施

- 主导航改为今日、口语、阅读、复习、记录；固定英日切换，所有学习页面在项目内。
- 桌面侧栏、双栏训练区；移动顶部语言切换、底部五项导航和单栏布局。图标使用项目内 SVG，字体使用本机字体。
- 内置英日各 6 个原创单元，共 37 道阅读题、25 个口语任务；正文、译文、句型、生词、题目、答案与解析同单元关联。
- 日语正文支持振假名与译文；零基础首页可直达假名。假名扩展到 104 个音节，五题随机抽样并保存成绩。
- 阅读支持选择、判断与填空，提交后显示原文依据，错题与收藏词进入复习。
- 口语支持跟读、自由回答、复述、准备计时与作答计时；录音后回听、自评、显式保存，未保存录音离开时提示。
- 课程依据阅读及该单元全部口语任务的完成情况推进，首页继续尚未完成的口语步骤。
- 英日记录分开，重复练习分别保存；阅读结果保存题目/答案/标题快照和内容版本。
- 个人录音使用 IndexedDB，结果与偏好使用 localStorage；支持包含录音的完整 JSON 备份与恢复。
- 旧版存储保留，记录页提供历史任务、自建词与原始数据归档。
- 保留原词库并合并单元生词，共 229 个去重词条；数据已拆为项目内 JSON，维护步骤见训练数据说明。
- 新增 148 条配音，映射共 650 条。新单元、句型、词汇与扩展假名全部有预生成地址；切换页面会停止播放。

浏览器作答在独立的 `127.0.0.1:3001` 测试环境执行，避免写入用户 `localhost:3000` 的学习记录。录音测试使用合成音频，不请求真实麦克风；真实设备权限、录音音质与人工听感尚需设备验收。

`web-debug-harness` 的 CDP 采集脚本无法匹配内置浏览器页面，改用浏览器状态、控制台、实际交互和截图验证，未生成自动 HTML 报告。中间开发错误已修复，以最终构建和刷新结果为准。

## 当前支持范围

当前是入门与考试专项训练，不是完整雅思四科或完整 JLPT 等级课程。N3/N2 等后续阶段需要继续补充数据；目标设置中的阶段表示学习方向，不是已具备的题库覆盖。PWA、原生桌面打包、自动口语评分和跨设备自动同步尚未实施。
