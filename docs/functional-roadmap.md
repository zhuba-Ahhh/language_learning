# LinguaDesk 功能现状与演进规划

更新日期：2026-10-05  
状态：功能演进建议尚未实施；目录整理 A+B 已完成，不改变产品支持范围。  
关联文档：[目录整理方案](./directory-organization.md)

## 1. 产品方向

将现有英日学习台逐步发展为“按目标组织学习、按练习结果安排复习”的语言学习工具。

雅思、JLPT、日常交流和职场场景作为不同学习目标，共用内容、练习、复习和记录能力；各目标保留自己的内容范围、题型及评价规则。

优先补齐以下学习流程：

> 选择目标 → 获取今日任务 → 进入材料与练习 → 提交结果 → 查看反馈 → 到期复习 → 阶段复测 → 调整计划

当前最主要的缺口是任务、材料、练习结果和复习安排尚未连接。增加考试入口前，需要让一条学习流程能够完整运行。

## 2. 当前功能盘点

以下功能盘点以代码为依据。目录迁移的检查与交互对照结果见[实施记录](./directory-organization.md#12-ab-实施记录)，不等同于完整功能验收。

| 功能     | 当前支持                                               | 主要边界与缺口                                 |
| -------- | ------------------------------------------------------ | ---------------------------------------------- |
| 今日学习 | 每日任务、每日一句及朗读、掌握词数、连续打卡           | 任务主要靠手动勾选，不能直接进入对应练习       |
| 学习计划 | 固定 30 天英日交替任务、预计时长、完成状态、热力图     | 无目标选择、时长设置、暂停、重排和多目标协调   |
| 词库     | 148 个内置词条，语言筛选、搜索、释义、例句、读音和朗读 | 无自建词条、导入、收藏、等级和内容来源管理     |
| 闪卡     | 翻面、自评认识/不认识、不熟词排到队尾、跨卡组复习      | 无跨天复习安排、遗忘后重学、拼写及听辨训练     |
| 口语     | 9 个场景、54 条句子、TTS 朗读、跟读提示                | 无录音、回听、自由回答、评价和历史对比         |
| 阅读     | 21 条分级资源条目，点击打开外部网站                    | 无站内文章、阅读题、批注、查词和生词收集       |
| 假名     | 46 个基础假名，平片假名切换、四选一、正确率与最佳成绩  | 无完整浊音/半浊音/拗音训练，无逐字薄弱项记录   |
| 语法     | 计划文案中列出部分句型和教材任务                       | 无独立讲解、接续规则、辨析与练习               |
| 听力     | 单词与句子 TTS、外部听力资源                           | 无音频题组、听写、精听、答案和解析             |
| 写作     | 尚未实现                                               | 无题目、编辑器、反馈、重写和版本记录           |
| 学习记录 | 本地保存任务、打卡、词汇标记、假名最佳成绩             | 无完整作答历史、能力趋势、数据备份和跨设备同步 |

材料以技术工作和日常生活为主，尚未形成按考试等级组织的课程或题库。阅读资源中有重复目的地，条目数不等于独立网站数量。

### 2.1 当前学习记录的含义

| 当前行为               | 当前含义                     | 后续需要明确的规则                               |
| ---------------------- | ---------------------------- | ------------------------------------------------ |
| 闪卡标记“认识”         | 一次主观自评                 | 区分自评、即时答对和延迟复习表现                 |
| 进入第 N 天            | 根据开始日期与今天的差值计算 | 支持按完成进度推进，或按考试日期重排             |
| 走到第 30 天           | 后续仍停留在最后一天         | 增加阶段完成、下一阶段及持续复习                 |
| 完成任意一天的全部任务 | 记录操作当天的打卡           | 区分今天学习、补做和提前完成                     |
| 重置全部进度           | 清空主要学习状态             | 当前未覆盖独立保存的假名最佳成绩，需统一重置范围 |

### 2.2 优先核验的体验问题

- 动态显示：显示动画只在顶层导航变化时重新扫描，新挂载的假名测验和词库内容可能保持透明。
- 复习统计：不熟词集合随掌握标记缩小，复习总数跟着变化，完成提示可能显示 0 个词。
- 闪卡交互（已修复）：翻面与朗读使用独立按钮，支持键盘操作，隐藏卡面退出 Tab 顺序；详见[修复记录](./architecture-less-plan.md#8-后续修复闪卡按钮嵌套)。
- 文案与能力：任务提到录音、生词录入，但当前没有对应操作入口。
- 内容校对：例如日语发音提示把“エンジニア”的“ニ”描述为需要拖长，应纳入内容审核。

上述问题应分别复现、修复和验证，不与纯目录移动混成同一批变更。

## 3. 雅思学习目标

### 3.1 目标设置

- 考试类型：Academic（A 类）或 General Training（G 类）。
- 目标成绩：总分与听、说、读、写单项要求分别设置。
- 当前水平：允许用户填写已有成绩；缺少成绩时可做入门诊断，不直接推断官方分数。
- 时间预算：目标日期、每周可学天数、每日可用时间。
- 学习重点：优先提升薄弱单项，兼顾其他单项维护。

A/G 类听力和口语相同，阅读和写作不同。Task 1 分别涉及图表等信息描述与书信，内容和反馈应按类型区分。

### 3.2 专项功能

| 专项 | 建议功能                                       | 反馈重点                               |
| ---- | ---------------------------------------------- | -------------------------------------- |
| 词汇 | 主题词、搭配、同义改写、拼写、语境填空         | 认得、听得出、拼得对、用得出分别记录   |
| 听力 | 分段音频、精听、听写、填空和匹配、答后查看原文 | 没听清、拼写错误、词义不懂、干扰项误判 |
| 阅读 | 文章与题组、限时作答、判断/匹配/填空           | 原文依据、同义替换、干扰项原因和用时   |
| 口语 | Part 1/2/3、准备与作答计时、录音回听、再次作答 | 流利与连贯、词汇、语法、发音           |
| 写作 | Task 1/2、计时、字数、草稿、版本对照、重写     | 任务完成、连贯衔接、词汇、语法         |
| 模考 | 分项与整套模拟、成绩历史、目标差距             | 单项短板、时间分配与稳定性             |

### 3.3 练习与模拟分开

- 练习模式：允许暂停、重听、查词和查看解析，记录是否使用提示。
- 模拟模式：按对应考试规则控制时间、播放和提示，提交后统一反馈。
- 两种模式的成绩分别记录；重复做过的题不能作为独立测评样本。

### 3.4 AI 辅助的使用边界

- 用于解释错误、生成变式、辅助写作修改及口语反馈。
- 写作反馈引用用户原文、解释修改原因，并支持用户重写后比较。
- 发音评价必须使用实际音频，不能从转写文本推断。
- 练习估分与正式考试成绩分开显示，保留评分依据和版本。
- 客观题以经过审核的答案与规则判分；AI 生成题目先审核再进入正式内容集。

仅上线词库或单项练习时，应标明具体支持范围，不呈现为完整雅思备考或完整模考。

## 4. JLPT 学习目标

### 4.1 目标设置

支持选择 N5—N1、当前基础、目标日期、学习时间和薄弱项。首批实际开放的等级以内容准备情况为准。

JLPT 考查语言知识、阅读与听力，目前不设口语和写作考试。“JLPT 备考”和“日语交流”可同时作为目标，分别记录达标情况。

### 4.2 分级能力

| 能力       | 建议功能                                                         |
| ---------- | ---------------------------------------------------------------- |
| 假名与发音 | 浊音、半浊音、拗音、长音、促音；看字认音、听音选字、混淆字符专项 |
| 汉字与词汇 | 词语中的读音、音读/训读、语境意义、近义表达与用法辨析            |
| 语法       | 接续、含义、例句、易混项对比、选项填空、句子排序                 |
| 读解       | 短文、长文、通知、信息检索；句子结构与答案依据                   |
| 听解       | 分级题型；练习模式提供分段和原文，模拟模式按规则播放             |
| 阶段测评   | 分项成绩、题型表现、耗时、错题复测、模拟记录                     |

### 4.3 考试规则与内容依据

- JLPT 合格需要同时满足总分与分项最低要求，学习安排应覆盖各项短板。
- 不同等级的考试科目、计时和成绩分类不同，应保留对应规则。
- 官方使用尺度分数；不能将普通练习正确率直接乘以 180 作为真实考试成绩。
- 初期优先展示正确率、用时、内容覆盖和薄弱点，缺少校准依据时不展示通过概率。
- 官方不公布完整的现行词汇、汉字和语法清单。词库的等级标签应注明教材或整理来源。
- 官方样题、原创练习和其他来源材料分别标记；内容入库时记录来源、可使用范围及审核状态。

## 5. 通用学习模型

### 5.1 五个产品概念

| 概念     | 内容                                     | 示例                                      |
| -------- | ---------------------------------------- | ----------------------------------------- |
| 学习目标 | 学习语言、目的、目标水平、期限、时间预算 | 雅思 6.5、JLPT N3、日本旅游、英语技术面试 |
| 学习内容 | 词、句型、文章、音频、场景及关联         | 一段租房对话关联词汇、语法和听力题        |
| 练习形式 | 用户如何使用材料                         | 闪卡、选择、填空、听写、排序、录音、作文  |
| 学习记录 | 实际完成了什么、结果与困难               | 作答、耗时、提示使用、错因、修改记录      |
| 学习安排 | 下一步内容与复习时间                     | 今日任务、到期复习、短板专项、阶段测验    |

### 5.2 复用与独立性

1. 语言与目标分开：英语可用于雅思和职场，日语可用于 JLPT 和旅行。
2. 内容与练习分开：同一份内容关联多种练习，避免各页面复制材料。
3. 练习与考试规则分开：共同题型复用交互，考试保留独立计时与评价。
4. 个人记录与内容分开：材料更新不能覆盖用户记录。
5. 熟练度按技能和证据记录：看懂、听懂、拼写、主动使用不合并成一个布尔值。
6. 计划与实际学习分开：未完成任务可以重排，已经发生的学习记录保持不变。

示例：一段日语租房对话可用于生活跟读、词汇复习、语法填空和听力理解；经过审核后，再关联适合的等级训练。

### 5.3 等级体系

- 原生保留雅思分项成绩、JLPT 等级以及课程自己的阶段定义。
- CEFR 可作为带来源、范围和版本的参考维度，不作为统一换算公式。
- JLPT 的 CEFR 参考不包含口语和写作，不可由一个考试等级推断所有技能。
- 首批通过英语和日语验证模型；第三种语言出现真实需求后再增加专属能力。

### 5.4 学习计划与复习

- 允许自由学习，不强制选择考试。
- 可配置目标日期和每日时间，考试日期可手动录入，后续再考虑日历服务。
- 多目标共享每日时间预算，用户设置主次，避免每个目标各生成一份超量任务。
- 优先处理到期复习，再分配新内容；逾期任务重排，不无限堆积。
- 支持暂停、跳过、更换材料和手动完成外部学习，标明结果来源。
- 先采用规则明确的复习安排；数据充分后再评估更复杂的调度算法。

## 6. 用户入口建议

| 入口 | 主要任务                               |
| ---- | -------------------------------------- |
| 今日 | 当前目标、继续学习、今日任务、到期复习 |
| 学习 | 按课程、等级、场景或技能选择内容       |
| 复习 | 生词、错题、语法与待重练内容           |
| 测评 | 阶段测试、专项测试、考试模拟           |
| 我的 | 目标、个人材料、学习记录、备份与设置   |

假名位于日语基础；雅思专项位于相应目标。导航变化应随功能上线逐步进行，目录整理本身不调整现有七个入口。

## 7. 内容与记录的持续维护

| 对象       | 最低要求                                           |
| ---------- | -------------------------------------------------- |
| 内容       | 稳定标识、语言、标签、来源、版本；等级需有依据     |
| 题目       | 关联材料、题型、答案、解析、考查点、审核状态       |
| 音频       | 对应文本、必要的时间段信息、可使用范围             |
| 学习记录   | 内容与题目版本、用户作答、结果、时间、提示使用情况 |
| 主观题反馈 | 用户原文/音频、评价依据、建议、评分方式与版本      |
| 个人数据   | 导出、恢复、删除范围明确；迁移前备份，迁移可验证   |

第一阶段仍可本地优先。引入录音、大量材料或跨设备需求时，再选择合适的媒体存储和同步方案；不把二进制录音塞入现有 localStorage JSON。

## 8. 建议实施顺序

| 阶段             | 优先交付                                                                           | 验收结果                                             |
| ---------------- | ---------------------------------------------------------------------------------- | ---------------------------------------------------- |
| P0：连通现有流程 | 修复体验问题；可配置目标；任务关联材料；自建生词；跨天复习；基础作答历史；导出备份 | 用户能从任务进入学习，保存结果，并在之后收到复习安排 |
| P1：验证考试学习 | 一个 JLPT 等级中的完整训练单元；通用听读题组；一个雅思专项                         | 讲解、练习、解析、错题、复测可连续完成               |
| P2：形成备考产品 | 扩展等级与题型；完整模拟；录音与写作反馈；计划调整；按需同步                       | 用户能识别目标差距，并据此调整下一阶段学习           |

### 8.1 首个功能版本的建议范围

- 保留现有内容与七个入口。
- 增加目标设置和任务进入对应功能的能力。
- 增加手动添加生词、统一词条身份和基本重复检查。
- 记录练习结果与下次复习时间，形成“今日到期复习”列表。
- 支持导出、恢复学习记录。
- 增加一个小型但完整的分级单元，覆盖材料、练习、解析和复测。

完整训练单元不等于完整等级课程；尚未覆盖的内容和题型应明确显示。

### 8.2 首批考试选择

如果尚未明确首批用户，可从 JLPT N5 的小型单元验证共用能力，复用现有假名和闪卡基础。若首批用户集中于雅思或 N2，应围绕该目标选取单元。

实际开发前需要确认首批目标与内容来源；本分析不假定用户本人处于零基础或某个考试等级。

### 8.3 后置能力

在学习流程验证前，暂不投入多语言全面覆盖、社交排行、复杂积分、插件市场、自动抓取全网内容和复杂自适应预测。

## 9. 效果衡量

- 一次“任务—学习—反馈—复习”流程的完成情况。
- 到期复习完成率与延迟复测正确率。
- 同类新题的表现，而不仅是重复旧题后的分数。
- 难度和模式可比时的正确率、用时变化。
- 用户是否能理解薄弱点，并采取下一步行动。
- 首次使用后是否持续学习；本地记录与主动反馈可先支持初期验证。

打卡数、在线时长和闪卡自评只能作为行为指标，不直接等同于语言能力或考试分数。
