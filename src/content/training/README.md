# 训练数据

所有学习材料由项目提供，浏览器加载时不访问外部词库或文章站点。

| 文件             | 内容                                            |
| ---------------- | ----------------------------------------------- |
| `data/en.json`   | 英语基础、雅思专项、IT 场景的完整学习单元       |
| `data/ja.json`   | 日语入门、N5 读解、生活与 IT 场景的完整学习单元 |
| `data/kana.json` | 清音、浊音/半浊音、拗音，平片假名与罗马音       |
| `types.ts`       | 单元、阅读题、口语任务和词汇的字段定义          |
| `index.ts`       | 内容目录、方向名称和完整性校验                  |

每个单元包含稳定 `id`、语言、阶段、方向、预计时长、训练目标、正文与译文、生词、句型、理解题、口语任务、版本和来源。正文与口语共享单元身份，避免任务文案指向不相关材料。

添加一个单元：

1. 在对应语言的 JSON 数组中添加完整对象，结构参考已有单元；ID 使用 `en-` 或 `ja-` 前缀。
2. 每题的 `evidence` 是正文段落的零基下标。选择题答案必须在选项中；判断题只使用 `True`、`False`、`Not Given`；填空给出明确的字数限制。
3. 口语任务包含实际问题、示范回答、译文、提示和作答时长。Part 2 可设置 `prepareSeconds`；示范不能代替问题。
4. 日语振假名格式是 `大学生[だいがくせい]`。去掉方括号读音后必须与 `text` 完全一致。
5. 校对语言、译文、题目和答案依据。内容为原创练习或取得允许使用的材料，记录来源；界面不提供外站跳转。
6. 在内容制作阶段运行 `pnpm audio:generate --align`，补齐缺失 CDN 音频及正文、示范、句型例句的词级字幕。已有匹配时间轴的资产不重新生成。网页只读取项目映射和 CDN MP3，不调用生成接口。制作阶段调用服务不等于 CDN 音频可在断网时首次播放。
7. 使用 Node 22.12+ 执行 `pnpm test:training`，再执行 `pnpm lint` 和 `pnpm build`。

已有 ID 不修改、不复用。修改题目时提升 `version`；已保存的阅读结果带有当时的题目、答案和标题快照。新增等级以实际材料为准，不添加空入口或将目标分数当成系统评分。

当前 12 个单元共 85 道阅读题、37 个口语任务。英语覆盖细节定位、同义替换、True / False / Not Given 和填空；日语覆盖身份、所属、时间、行动顺序、通知和职场确认。每道题均带答案、解释和段落依据，数据直接随项目发布。

`SpeakingTask.optional: true` 表示口语加练，在任务页标为「加练」，不加入自动推进的必做任务，也不让原本完成的单元变成未完成。当前 12 个加练使用各单元已经配好的句型例句，复用现有 CDN MP3 与精确字幕，不发起新的生成请求。新增题目使用新 ID，原有题目 ID、正文和音频映射保持不变；本轮单元内容版本为 2，历史成绩按题目快照显示。

词库页同时合并原有 188 个词条和单元生词，按语言与词面去重。候选词生成脚本只用于内容制作，不在用户学习时调用；外部候选需要补充中文释义、语境和校对后再入库。

## P0 学习闭环

- `grammar.ts` 为现有 12 个单元提供句子拆解、用法提示和 24 道句型题。拆解拼接必须等于原有例句，配音和时间轴不变。
- 阅读页的「句型」「精听」复用当前内容；精听使用原有句型音频，支持循环、隐藏原文、听写和核对。当前是句型短句精听，不是完整 JLPT/IELTS 听力题组。看原文后提交标为辅助练习。
- 今日任务按目标筛选路线，再按 15/30/45 分钟预算安排。分钟数是预计用时，不是硬计时。假名基础与到期复习优先，超出预算的内容仍可自由练习；当前仅安排一个学习单元。
- 「完成」保留旧规则；「掌握」要求当前版本阅读至少 80% 正确、必做口语的最近自评均为熟悉。不阻止自由学习，不换算考试分数。
- `drillResults` 保存句型与听写的答案快照；错题进入现有复习。新字段均兼容旧备份，录音自检保存为 `selfChecks`，没有自动发音评分。
- Node 22.12+ 下运行 `pnpm test:workflow` 验证内容、任务预算、目标路线、掌握判断与备份数据校验。

## 划线与配音维护

`words` 中的词自动实线标记。`marks` 是原文中的精确文本：`{ text, kind: 'phrase' | 'pattern', note, wordId? }`；短语实线、句式虚线。`wordId` 可连接词面变化（如 `solving problems` → `solve a problem`），保留释义与复习身份。只标重要内容；校验要求文本出现在该单元的正文、示范或句型例句中。

CDN 地址在 `src/lib/audio.generated.json`。时间轴在 `src/lib/audio.timings.json`，每条保存同一 MP3 的 URL、秒单位时长及 `[原文起点, 原文终点, 音频起点, 音频终点]` 数组；文本偏移是 JavaScript UTF-16 下标。界面只在时间轴与音频 URL 一致、词边界完整时启用定位，不按字数估算。日语同时保留词汇整体边界和振假名。

脚本每次请求前写入 `docs/audio/receipts/`，返回后保存原始结果。请求结果不明时先检查回执，不盲目重发。仅重新解析已有字幕、不发生成请求：`pnpm audio:generate --refresh-timings --limit=0`。配音仍需人工听感校对，服务提供的字幕时间不代表经过人工逐词审校。
